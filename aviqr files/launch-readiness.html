App Store Accounts

ACC-01

Apple Developer Account

Required

Publishes in.aviqr.app to the App Store, signs builds, and issues the APNs key that powers order and low-stock push notifications and TestFlight betas.

Set up
Apple ID enrolled in the Apple Developer Program (US$99/yr) · App Store Connect access · APNs Auth Key (.p8) for push · app already declares camera, photo library, notification, location and Face ID usage strings.
Owner
Use a shared company Apple ID, not a personal one — losing access to a personal ID is the single most common App Store lockout.

ACC-07

WhatsApp Business Platform

Required In use: Twilio

Sends order updates and OTPs over WhatsApp. Confirmed in this repo's own privacy policy (app/privacy.js): "Twilio — SMS/WhatsApp notifications (phone number, order summary)." No separate Gupshup/Interakt/Meta Cloud API integration appears anywhere else in the codebase.

Set up
Twilio account with WhatsApp Business API enabled · Meta Business Manager verification (Twilio brokers this, but Meta still requires a verified business) · approved message templates for order updates.
Owner
